# Fake-News-Detector
Project Name: Fake News Detector

Description:
This project uses Machine Learning and Natural Language Processing (NLP) to classify news articles as Real News or Fake News. The model is trained using Logistic Regression and TF-IDF Vectorization. A Streamlit web application is used for user interaction.

Technologies Used:
- Python
- Scikit-Learn
- Pandas
- Streamlit
- Machine Learning
